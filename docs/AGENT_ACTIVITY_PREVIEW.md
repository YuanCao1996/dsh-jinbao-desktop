# 智能体动态（独立桌面候选版）

此功能加入 0.2.4 候选包，默认关闭。公开更新源仍为原发布版本。

在设置网页“直播展示”勾选“在大框战况页显示智能体过程”，也可以点击悬浮窗设置 →“直播展示：智能体过程”。设置会保存，重启后保留。选择大框并打开战况页，即可在已有建议下方看到过程区域。聊天、字幕、横向滚动和收起状态隐藏该区域。

显示真实的排队、模型请求、工具执行、完成或失败状态及耗时。开启后，新任务请求流式响应；官方服务通过云端 DSH 执行，自有 Key 通过本机 DSH 执行。只展示模型明确输出的公开正文草稿，内部推理不展示。厂商返回普通 JSON 时保留完整回答，不制造逐字动画。

草稿标注“尚未完成校验”，不能当成最终建议；任务结束、失败或取消时移除草稿。最终建议仍经过原有对局有效性检查。切换对局清空过程记录，关闭开关也会清空；两者均不删除用户记忆。关闭展示不会取消模型任务。

过程区最多保留 40 行和最近 8 个任务，只更新变化的行。向上滚动暂停跟随，点击“回到最新过程”继续跟随。它不参与字幕、语音、手机同步或 Agent 上下文组装。工具参数和原始结果不展示，正文中的常见凭据、邮箱和内部地址会遮蔽。

开启后从下一次分析开始记录过程。新一步模型只输出半句时会清除上一步草稿，完整句子到达后再显示。长草稿保留脱敏后的最新部分。短暂断网显示重试与恢复状态，沿用原任务接收结果；软件重启或切局后不保留旧过程，已结束任务的迟到事件也不会重建展示。

手动聊天优先于后台自动建议。后台队列已满时可撤下一条自动任务，让聊天进入；已有手动问题不会被挤掉。云端取消请求收到回执后，还需等待旧任务真正退出再交接，过程区显示等待状态。正常中断后，自动战况和出装保留待处理的任务，1 秒后允许下一次调度重试，不套用生成失败的长冷却。退出程序会打断交接等待。

直播需开启设置中的“允许截图、直播和录屏显示助手”，在直播软件预览中确认实际采集效果。助手自己的 OCR 仍按原流程临时避让整个悬浮窗。独占的游戏捕获能否带入悬浮窗取决于直播软件的捕获方式。

自动验收覆盖开关持久化、鉴权、对局隔离、取消、断流、工具参数完整性、滚动跟随和模式切换。真实对局与直播软件长时间运行尚待实测。

2026-10-26 联动验收：完整串行回归 367 项通过。本机 43 份历史日志共 8,852 条事件，分别以 12 秒、25 秒模拟传输延迟；每组 221 次聊天测试提问均完成，自动战况建议过期发布和迟到草稿泄漏均为 0。回放使用明确标记的占位响应，不评价真实策略质量。另做一次真实官方云端交接测试，观察到旧任务退出等待，两次任务创建均返回 202，手动问题约 10 秒收到回复。

后续生命周期验收：完整串行回归增加到 380 项，全部通过。切换模型先等待旧引擎关闭；退出中已开始的初始化会被关闭，不再执行模型。网页入口先停止接收新请求，已经接受的设置保存仍会完成。每个清理步骤都会尝试执行，失败只记录步骤名到本机 `shutdown-state.json`，不保存原始错误或凭据。

更新重启通知延后到清理成功之后，并等待 IPC 发送完成，兼容旧启动器。新版入口不把信号终止视为正常退出。已用实际旧 0.2.3 入口、新版自身入口和隔离测试进程验证升级、同配置立即重启、强制终止后重新启动及配置保留；真实旧入口的 IPC 测试确认清理失败不重启，成功才交接。真实对局、OBS 长时运行和用户所用杀毒软件仍需另外验收。
