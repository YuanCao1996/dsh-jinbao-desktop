## 第三轮：按需历史与原生压缩

- 新增 `query_match_events` 只读工具。Agent 按需请求本机读取当前对局的归档页，而不是把整份日志拼进初始请求。支持关键词、事件种类与游标；一次最多 10 条精简记录、14 KB 返回值，一轮最多 4 次请求。本机一次最多扫描 8 个有界块（4 MB），稀疏状态日志不会立即挡住关键事件。
- 可查询购买、海克斯候选/选择、聊天、建议与精简状态字段。聊天解析批次中的嵌套购买也可找到；保留候选、确认状态与不确定性，隐藏本地路径和玩家标识。过长文字明确省略，关键词查询返回命中附近的片段。
- 请求绑定当前游戏、对局、任务与账号。拒绝模型传入文件路径、其他会话或用户；换局后不上传旧页；已完成任务不再执行过期截图和日志请求。旧客户端未声明能力时不注册新工具。
- 修复 worker 只为王者开启原生压缩的问题，LoL 也使用现有 DSH 压缩组件。网关只有在原始会话可靠归档后，才复用原生摘要与最近消息缩减内存副本；归档失败保留原文。已完成的桌面任务轮询收据可以过期，原始归档保留。
- 真实压力测试曾在第七轮失败：已经物化的摘要被再次压缩，加入框架标记后不再更短，被 DSH 拒绝。已补精确回归，改为直接复用已验证摘要。
- 自动建议已验证进入建议日志、战况页与播放数据；新局清除旧局建议。自动任务继续保留阶段和表达约束，不发送筛选事实 JSON；事实通过工具读取。
- 设置页可显示此次预览的版本更新日志。

实测结果：

1. 真实云端 Agent 在初始最近窗口之外查到 00:45 购买“遗失的章节”的嵌套日志与测试标记，未读取另一局记录。
2. 真实云端自动教练根据构造对局生成建议，写入 `cloud-advice` 日志并进入战况页数据。本次还取得了一条公开强化资料，但不能据此认定联网检索已稳定。
3. 修复后完成 8 轮真实模型对话，触发原生压缩与两次摘要复用，最后准确保留首轮随机代号；8 轮均确认归档成功。
4. 同一客户端切换到新局后，真实模型没有带入上一局代号。
5. 100 轮模拟运行验证网关保留副本有界；这不是 100 轮真实模型对话。
6. 客户端 24 项、既有功能 157 项全部通过；预览后端日志隔离 3 项、保留策略 2 项、实际 DSH 原生压缩 3 项通过。运行时开关、模式与身份测试也通过。

这些仍是构造数据和协议验收。真实游戏中的视觉效果、完整对局的时延/额度压力、跨局历史显式查询、手机交互和两种运行模式切换仍需继续验证。

## 第二轮修复

第二轮产物版本：`0.1.49-cloud-preview.2`，包名 `jinbao-cloud-preview-20261024-r4.zip`。最新包见文首。

- 云端 LoL 提示词区分 KIWI、普通 ARAM 和未知模式；未知模式不再默认宣称是海克斯大乱斗。
- 联网检索增加完整 JSON-RPC SSE 事件读取，支持多行事件、通知、中文、取消和体积限制；不必等待服务端关闭流。为 RSS 备用检索预留时间，拆分英雄名与游戏、模式、通用意图词。

## 已验证的结果

独立 Node 客户端可以启动现有设置网页、加密保存登录凭据，并把聊天交给服务器 DSH。它没有启动、安装或调用本机 DSH Desktop。

真实云端测试完成两次任务：普通问候，以及读取构造的对局事实。第二次任务中，服务器 Agent 主动调用 `get_current_match_state` 和 `get_recent_match_events`，回答了安妮、6 级、03:00 购买残疫。任务产生了 `quota_settled` 事件。测试拦截本机教练地址，实际调用次数为 0。

这证明了真实认证、云端 Agent、工具取数、返回回答和额度结算链路；构造数据不能代替真实游戏验收。

后续真实云端看图测试也通过：Agent 调用 `inspect_latest_screen`，触发客户端采集与上传，视觉模型正确读取既有无隐私测试图中的随机校验文字，任务完成额度结算。这是测试图片往返，不是真实游戏视觉效果验收。

资料工具真实调用完成，但应区分调用成功与取得有效证据：本地查询返回英雄基础资料，未命中该模式安妮攻略；联网首次因攻略站点缺失失败，预览配置补齐站点并增加模式过滤后，复测仍因检索超时未取得可用资料。不能宣称联网攻略已可稳定使用。

## 实现边界

| 模块 | 当前实现 |
| --- | --- |
| 客户端启动 | `tools/cloud-desktop/main.mjs`，独立状态目录，复用设置页和悬浮窗入口 |
| 游戏采集 | `--collect` 复用现有采集监督器，默认不启动 ADB |
| 聊天与自动教练 | 共用云端任务适配器；自动教练通过 `--coach` 单独启用 |
| 会话 | 按设备、游戏、对局生成稳定会话标识；更换对局取消旧任务 |
| 上下文 | 当前结构化事实、最近 20 条事件和最多 6 条明确偏好，总计不超过 24 KB；不上传完整本地历史 |
| 看图 | 按云端请求采集；采集前后校验游戏、对局和时间；没有画面时明确返回 unavailable |
| 凭据 | Windows 当前用户 DPAPI 加密，独立于 DSH Desktop 凭据服务 |
| 云端安全 | 服务端确定用户身份、模型权限和额度；任务归属校验；内部服务密钥仅在服务器 |
| 部署 | 独立预览进程、端口和会话目录；生产默认路由保持现状 |

注意：24 KB 是本地发送事实的上限，不代表模型一轮只接收这部分。云端 DSH 仍会维护本局会话、使用工具结果并执行原生上下文压缩。完整历史的按需检索和长局压力测试仍需继续完善。
