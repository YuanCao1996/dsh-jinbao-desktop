# 开源和商业运营边界

本仓库 MIT 许可仅覆盖仓库中具有相应权利的代码；第三方组件继续适用其许可。该许可不授予第三方攻略数据库、游戏素材、商标、模型服务或游戏平台的商业使用权，也不表示获得游戏平台认可。

截至 2026-10-22，下面事项需要产品运营方取得证据并复核，不能通过增加免责声明视为完成：

- 官方云端模型：核实当前供应商套餐是否书面允许向第三方终端用户提供服务、统一计费和转供。OpenCode Go 的公开接口本身不等于转售授权；未确认前不应扩大商业推广。参考 [OpenCode 服务条款](https://opencode.ai/legal/terms-of-service)。
- 游戏辅助：针对实时海克斯排名、装备建议、截图识别和国服日志访问，分别确认 Riot、腾讯适用政策、注册及授权要求；避免自动操作游戏、读取非公开信息或宣传官方认可。参考 [Riot 第三方应用政策](https://support.riotgames.com/en-us/riot/events/third-party-applications)、[LoL 开发者政策](https://developer.riotgames.com/docs/lol)、[腾讯游戏许可及服务协议](https://game.qq.com/contract.shtml)。
- 数据库：内部保留来源、获取方式、授权范围、更新时间及必要署名记录。对外响应不带来源字段不免除授权与署名义务。没有证明可商业复用的数据不得作为已获授权资产宣传。
- 隐私：官网隐私政策需补充电脑日志、截图、聊天、邮箱、IP、手机配对、云端模型供应商、保存期限、删除方式及退出后的处理。玩家名及截图可能含第三方信息，优先最小化采集；公开示例和日志应脱敏。
- 协议：区分桌面开源代码的 MIT 权利与账号、托管模型、商业检索服务的使用条款，避免服务协议把开源许可已授予的权利一并禁止。
- 境内 AI 服务：请按实际面向公众的服务形态复核生成式 AI、算法备案及生成内容标识要求。参考 [生成式人工智能服务管理暂行办法](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)、[人工智能生成合成内容标识办法](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)。

以上为产品整改事项，不能替代针对实际运营主体、数据来源和供应商合同的法律意见。
