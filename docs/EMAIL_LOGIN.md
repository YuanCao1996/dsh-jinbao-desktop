# 邮箱登录

设置页支持邮箱验证码登录，以及将邮箱绑定到当前金宝云端账号。服务端未配置 SMTP 时，入口显示“邮箱服务正在准备中”，用户仍可使用现有体验入口或自己的 API Key。

验证码 5 分钟有效、最多尝试 5 次、使用后立即失效。重新发送间隔 60 秒。登录凭据通过现有桌面凭据存储保存，验证码不持久化到客户端文件。

已有体验或微信账号应先登录，再点击“绑定到当前账号”。绑定成功后，在其他电脑使用该邮箱登录会沿用同一账号和额度。首次使用邮箱的新用户仍受现有 IP 体验名额规则限制；邮箱登录不会增加名额或重置额度。微信与邮箱账号不会自动按昵称合并。

邮箱登录保持用户已经选择的自有 API Key 模式。手机网页支持同一邮箱登录并查看已同步的电脑对局；手机会话只允许查看和提问，不能上传电脑状态或执行回答。可在设置中开启或关闭同步，原 App 微信配对继续兼容。DSH 宿主自身认证独立于金宝账号。

服务端提供三个独立接口：`GET /desktop/auth/email/capabilities`、`POST /desktop/auth/email/send`、`POST /desktop/auth/email/verify`。商业后端、邮件配置和邮件密钥不包含在桌面安装包中。
