# 第三批：受限DSH工具与自适应观察

日期：2026年10月13日。

## 实现与边界

新增独立DSH插件 `tools/generic-game-assistant/plugin.mjs`，默认关闭。
没有注册到当前启动器、已安装DSH配置或发布白名单，未重启宿主、发布客户端或改动服务器。

启用后的人工入口是 `genericGame` 服务，模型不能启动/选择窗口或覆盖用户授权。
宿主必须提供可信 `genericGameActivity.specializedActive()`；缺失、非布尔结果或LoL等专用游戏活跃时拒绝开始观察。
当前正式桌面入口尚未提供这个活动探针，因此不要直接将实验插件启用为正式模式。

每局独立 `generic-gomoku-*` 会话，复用现有无游戏业务逻辑的 `openCoachSession` 原生持久化API。
不导入LoL适配器、采集器、提示词或状态。对话历史由DSH原生会话管理，避免每次重复拼接本地历史。

本批模型接收本地棋盘识别后的结构事实，尚未增加云端视觉图片工具或通用文字OCR。
未知执子、规则和回合不会强行补齐；解释允许携带不完整状态，但不能声称已验证最佳落子。

## 四项工具

| 工具 | 能力 |
|---|---|
| `generic_read_state` | 读取当前授权局面；超过5秒的事实不作为当前状态返回 |
| `generic_observe` | 当前窗口局部观察；每轮最多两次，并受本地限额约束 |
| `generic_plan` | 提出窗口内ROI、清晰度与间隔；不能选择其他窗口/路径或开启自动模式 |
| `generic_reply` | 提交最终回复，最多256字，空回复/超长回复拒绝 |

工具仅在通用Agent作用域注册。使用native工具模式，关闭继承工具，增加执行白名单。
没有Shell、任意文件读取、网页访问、其他用户会话或自动鼠标/键盘操作。
通用作用域使用完整独立系统提示词，避免继承现有LoL/王者人设。
工具进度只发名称和开始/完成/失败，不发送思考内容、凭据或完整工具参数。

每请求最多8次工具调用、12个模型步骤、55秒DSH总等待时间。
回复缺失明确失败，不返回空成功。超时、取消、切换对局仅清理本模块所属会话。
等待游戏不会预热Agent或发起模型请求。

## 本地观察调度

- 只有人工明确选择 `automatic=true` 才创建自动观察定时器，默认手动。
- 基础约2秒；连续稳定帧约6秒；检测变化后短时间可加快到1秒。
- 串行执行，无积压截图队列；人工/模型观察共用每分钟40次上限和至少1秒间隔。
- 连续三次失败暂停自动采集，人工重试仍受频率与预算限制。
- 模型计划最长30秒；不能修改目标身份、输出目录或硬限额。
- 清晰棋盘定位后，本地自动学习带边缘余量的裁剪区域，无需先调用模型。
- 不确定/布局识别失败时恢复概览计划，避免反复盯错区域；无效帧清空旧事实。
- 相同图片和几何复用像素识别结果，只更新时间；旧会话迟到结果丢弃。
- 观察本身不触发LLM。模型仍由用户提问启动，截图频率不会放大模型调用量。

## 发现并防护的SDK混载风险

本机产品工程 `node_modules` 和上层 `D:/work/DSH/node_modules` 有不同SDK实例。
`dsh-scope`作用域标识不跨实例共享，即使版本相同，混用也可能将作用域提示词误注册为全局。

增加 `sdk-check.mjs`：核对tools/system-prompt与本模块使用同一物理scope模块。
并在注册前校验真实服务实例。缺失或混载直接拒绝，不降级为全局注册。
当前开发环境混载时不可直接启用，需在下一批独立测试配置/完整SDK安装中接入。
没有为解决这个问题重装现有依赖或修改当前DSH配置。

SDK集成测试将代码与单套依赖复制到独立临时目录，使用真实工具注册、权限校验和提示词拼装；
模拟Agent驱动与模型回复。测试结束仅删除已校验归属的临时目录。

## 验证

`npm.cmd run test:all`：原有24项、新模块65项，全部通过，无跳过。

覆盖：

- 默认关闭零活动、专用游戏活跃时拒绝通用采集。
- ROI、TTL、预算、稳定降频、变化加速、连续失败暂停。
- 窗口授权取消、停止后的迟到结果、旧事实失效与局部区域学习。
- 真实SDK工具可见性、禁止全局注册、Shell/LoL私有工具不可调用。
- 模型参数不能改变目标/路径；每轮观察限额和256字正式输出。
- 多轮共用独立Agent、缺失回复、启动并发、取消与超时。
- 棋盘像素 → 状态 → SDK读状态/计划工具 → 最终模拟回复的有界完整链路。
- 通用系统提示词隔离后，原作用域的提示词和工具仍保持原样。

这些测试不等于真实DSH宿主或云端模型联调；没有声称真实模型已完成自主看图。
上一批真实Windows窗口截图测试是独立证据，本批未重新运行窗口测试。
