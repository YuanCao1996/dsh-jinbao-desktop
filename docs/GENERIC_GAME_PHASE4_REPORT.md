# 通用游戏助手第四批：独立实验宿主

## 本批完成

- 独立进程、默认127.0.0.1:3094、独立配置和会话目录。
- 不启用现有LoL的启动器、通用教练请求构造器或全量DSH工具包。
- 使用本机完整SDK的同一依赖闭包，单独复制依赖，不安装、不更新现有node_modules。
- 挂载真实SessionStore、JSONL持久化、AgentLoop、SystemPrompt、ToolRuntime和pi-ai适配器。
- 模型凭据仅从实验启动环境进入内存；不读取现有凭据文件，不提供网页Key输入或Key输出接口。
- 实验控制页支持窗口选择、明确授权、可选自动采样、单次观察、停止、本局对话和工具进度。
- 初始棋盘是浅色占位网格，未知状态不显示为已识别事实；观察过期后清除显示棋子。
- 页面仅监听回环地址，检查Host、Origin和每次启动随机令牌；请求JSON上限8KB、连接数上限12。
- 窗口枚举共享单次在途请求；操作单飞，停止不受问答锁阻塞。
- 排除Windows桌面壳窗口；LoL游戏进程存在时拒绝通用模式观察，不干预LoL进程。

## 已执行验证

- 原有产品回归：24项通过。
- 通用模块回归：67项通过，总计91项，无跳过。
- 真实DSH AgentLoop：读取状态工具→最终回复工具；仅实验Agent看见四项工具；JSONL会话写入独立目录。
- 同局第二轮真实AgentLoop调用复用同一会话，并在模型输入保留上一轮问答。
- 连续问答测试发现并修复回合结束问题：最终回复调用DSH原生`concludeTurn()`，不再仅靠后置pre-step拒绝结束，避免下一轮请求挂起。
- 真实pi-ai HTTP链路：本机受控SSE端点接收模型请求，两次模型响应分别驱动状态读取和最终回复。
- 验证HTTP请求的模型名、认证头、仅四项工具、工具结果回传，以及不重复调用最终回复。
- 入口安全测试覆盖错误Origin、缺失令牌、超限JSON、未配置模型。
- 控制页实测桌面视口和390px窄屏，无横向溢出；成功列出窗口，未选择或授权任何用户应用。
- 受控真实Windows窗口复测：整窗/裁剪均225格全部正确；截图447/436ms，本地识别14/6ms，无整桌面兜底。

模型回应在测试中由受控端点提供：`real_agent=true`、`real_http=true`、`external_cloud=false`。
不能把上述结果称为外部模型识别准确率或真实棋局棋力验证。

## 隔离与性能边界

- 默认不注册到生产插件列表和正式发布包，现有LoL目录无改动。
- 自动观察默认关；本地自适应间隔、40次/分钟采样限额和失败暂停继续生效。
- 自动观察不会自动调用模型；只有明确提问才调用。
- 单问答最多12步/8次工具/2次追加观察/55秒，模型单次输出预算2048 tokens，最终展示最多256字。
- 工具权限是native受限模式，只有状态、授权窗口观察、短期观察计划、最终回复四项，无shell/文件/联网搜索/游戏输入工具。
- 采样不读取整个桌面；PrintWindow失败拒绝，不降级到桌面截图。
- 进程活动检查不编译截图组件，避免每次检查额外C#编译。
- 实验依赖准备的20～30秒开销仅发生在启动准备，SDK复制不在采样或问答热路径中。
