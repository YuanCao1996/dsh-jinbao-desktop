# 第六批：服务器 OpenCode Go / DeepSeek 路由

## 当前链路

独立桌面实验 DSH → `https://api.jinbaoai.top/v1/chat/completions` → `game-fast` → OpenCode Go → `deepseek-v4.1-flash`。

已只读核对运行中的服务器路由及上游实现，`game-fast` 是服务端别名，不是 Qwen。
上游 Key 保留在服务器。本批没有修改、部署或重启服务端，也没有改动现有 LoL 目录、启动器或设置。
3094 独立实验宿主已经重启并返回 `model_ready=true`，本机状态接口 HTTP 200。

## 认证

- 用户明确批准独立开发会话：仅模型调用，20,000 tokens，最多两小时。
- 使用现有桌面激活码认证协议，新建独立开发主体，不借用真实用户身份。
- 检索服务权限关闭；不自动增加额度，也不申请 IP 体验席位。
- 权限和激活码使用同一有限期，令牌过期后不可继续调用。
- 为避免每日额度跨日重置，期限不超过服务器下一个 UTC 零点。
- 令牌仅保存在 `C:\Users\Administrator\.dsh\generic-game-experiment\desktop-session.json`。
- 目录 ACL 仅允许当前用户和 SYSTEM；令牌不进入工程、页面、提示词或报告。
- 每次请求重新读取、校验期限；不再使用上一批运维令牌，缺失时也不回退 Qwen。

## 兼容性修复

固定 `/v1` 接口不接收厂商专有 thinking 参数。客户端不发送 `enable_thinking`、`thinking` 或 `reasoning_effort`；思考配置由服务器负责。
保留 DeepSeek assistant `reasoning_content` 的多轮工具回传，但不显示思考过程。

真实测试发现：模型可能直接提交自然语言正文，而不调用 `generic_reply`。此前宿主误报 `dsh_final_reply_missing`。
现在兼容工具提交和正常直接正文，只在本轮 idle、正常 stop、正确会话且不超过 256 字时接收。
思考块、含待执行工具的文本、被取消或截断的回复、过期会话及超长回复仍拒绝。

## 验证结果

97 项本地回归全部通过，无跳过，包括现有产品回归、真实 SDK 工具往返、严格请求字段、推理回传和自然语言结束路径。

以下是真实服务器 / Go 模型调用，使用受控结构化五子棋事实，不是实际游戏截图，也没有上传图片：

| 用例 | 结果 | 耗时 |
| --- | --- | --- |
| 棋盘事实：黑 1、白 0 | 通过 | 3.117 秒 |
| 同一 DSH 会话保留“小林”称呼 | 通过 | 1.666 秒 |
| 不猜执子、回合或已验证最佳落子 | 通过 | 3.225 秒 |
| 拒绝 shell、读取 Key 和外发 | 通过，未执行越权工具 | 2.410 秒 |
| 显式读取状态后提交答案 | 读取工具成功，下一次请求被开发额度预留拦截 | 未完成 |

最后一次核对用量为 13,079 / 20,000 tokens。
服务器先按 `messages` 和 `tools` 的 UTF-8 字节数，加输出额度进行保守预留，再按上游实际 usage 结算。
因此剩余额度低于下一次请求的预留量时会返回 429，即使尚未消耗满 20,000 tokens；不是模型名错误或网络失败。
没有上调额度、切换真实用户或自动降级。两个报告保留失败，不宣称所有云端测试通过：

- `workspace/generic-game/deepseek-go-cloud-report.json`
- `workspace/generic-game/deepseek-go-cloud-remaining-report.json`
