# 使用与排障

## 首次启动

1. 安装 [DSH Desktop](https://deepseek.com/harness/)，下载并完整解压金宝 ZIP。
2. 双击 `开始使用.cmd`，等待悬浮窗显示“等待进入游戏”。安装或升级时若提示关闭 DSH，先保存工作并关闭，再重新启动金宝。
3. 点击悬浮窗“设置”。默认金宝官方服务，点击“一键开通”领取 IP 体验；也可选择使用自己的模型 API Key。

IP 体验首批 30 个公网出口，每个名额累计 1 亿模型 token，同一出口共用；换 IP 可能占用新名额。无需 DeepSeek 账号或 Key。微信网站扫码尚未开通；已有 App 配对及激活码在设置的“其他登录方式”中。

LoL 在本机运行后自动采集。王者需连接一台已授权 USB 调试的 Android 手机，并在[统一金宝 App](https://www.jinbaoai.top/#download)中开启游戏采集。ADB 已随包提供。

以后双击桌面“金宝”。保留最初解压目录，也可继续使用原来的启动入口。

## 自动更新

从 0.1.10 起，每次启动及运行中每 6 小时自动检查官方更新，在后台下载并验证签名、文件大小和 SHA-256。下载完成后悬浮窗提示“下次启动自动更新”；退出金宝后再次打开同一个入口即可切换，无需重新下载 ZIP。

登录、API Key、对局和窗口设置保留在原用户目录。网络失败继续使用当前版本；更新损坏不切换，新版入口启动失败会回退。插件需要重载时，金宝提示先保存工作并关闭 DSH，再自动配置启动，不会强制关闭宿主。设置的“高级诊断”可查看更新状态。

0.1.9 及更早版本还没有更新器，需要先下载、解压一次 0.1.10 或更新包。更新的是金宝组件，DSH Desktop 和手机 App 仍使用各自的更新方式。

## 悬浮窗

- 标题栏拖动，收起后点击图标展开；× 或托盘“退出”停止金宝及本次采集，保留 DSH 运行。
- 拖动右下角手柄调整窗口大小，自动记住尺寸。内容区直接滚动，按住 Ctrl 滚轮调整正文大小；“设置 → 外观”中可调字体和背景不透明度并自动保存。`Ctrl+Alt+J` 切换完整交互，聊天自动进入交互模式。
- 大乱斗选英雄时自动打开胜率页，展示己方、可见对手和备选席英雄；换英雄或重掷后自动更新。
- 胜率页展示双方英雄的样本胜率和强度（T0、T1 等），隐藏玩家名和场次，按英雄胜率降序排列，无数据置后。对局计时显示游戏已进行的时长。
- 各游戏、对局的 Agent 会话独立，由 DSH 保存和恢复。等待游戏时不主动调用模型。

## 常见问题

| 问题 | 处理 |
|---|---|
| 无法启动或需要修复安装 | 打开 `高级维护.cmd`；修复安装前保存工作并关闭 DSH。 |
| 悬浮窗被游戏遮住 | 切换无边框或窗口模式。 |
| 没有建议 | 设置中展开“高级诊断”，检查教练服务、模型和日志状态；端口 3081/3084 不能被其他程序占用。 |
| 王者无日志 | 检查 USB 调试授权、App 采集开关；多台手机时只保留目标手机。 |
| LoL 无日志 | 先进入游戏；采集通过本机 LCU/Live API 读取。 |
| 官方服务名额或额度不足 | 换用自己的 API Key；攻略检索权限独立，不随 BYOK 自动开通。 |
| 自有模型认证失败 | 检查 API 地址、模型 ID 和 Key，保存后重试。 |
| 战绩、胜率或海克斯选项缺失 | 尚无数据就显示未知；海克斯面板使用 Windows 中文文字识别，需游戏保持前台。缺少中文识别组件时可在聊天中输入候选项。 |
| 本机已有旧开发版悬浮窗 | 启动器会沿用旧窗口，旧模型配置不会自动迁移。 |

已验证 DSH Desktop 0.2.0-rc.2、SDK 0.1.5-rc.2。共享依赖版本不一致时按安装器提示处理，不强行覆盖。

## 回退安装

关闭 DSH，将用户状态目录 `profiles/desktop` 中的 `cordis.patch.yml.jinbao-时间戳.bak` 恢复为 `cordis.patch.yml` 后重新启动。默认状态目录是用户目录下的 `.dsh`；设置了 `DSH_HOME` 时使用该目录。
