# 快速开始
1. 先安装 [DSH Desktop](https://deepseek.com/harness/)，运行一次后关闭。
2. 下载 Release 中的 Windows ZIP，右键解压全部，双击“开始使用.cmd”，选择安装。
3. 重启 DSH，再选择“打开设置”。不要在 ZIP 压缩预览窗口里运行安装。
4. 配置自己的模型 Key，或通过手机配对后使用已开通的金宝云端额度。
5. 启动 LoL 或王者日志采集，保持设置页打开查看实时策略。

王者需要金宝 App 的游戏采集功能、USB 连接及 USB 调试授权。ADB 已在 ZIP 中提供。手机配对 APK 为 arm64-v8a。
新用户仅用 BYOK 进行模型调用不需要微信登录；云端模型和攻略检索需要独立开通权限。

## 安装或检测失败
- 插件依赖版本不一致：当前验证宿主为 DSH 0.1.5-rc.2；暂未验证其他版本，不要覆盖共享依赖强行安装。
- 教练未启动：关闭并重启 DSH，检查安装是否成功、3081/3084 端口是否被占用。
- 王者无日志：确认 ADB 能看到手机并完成授权，金宝 App 已开启游戏采集。
- LoL 无日志：先运行客户端并进入游戏；局内状态来自游戏本机 API。海克斯画面 OCR 不在此轻量包中。
- 模型认证失败：核对厂商地址需包含正确 API 前缀（常为 /v1）、模型 ID 和 Key。
- 云端或检索权限不足：微信登录与商业权限是两件事，需要开通对应功能。
- 退出电脑登录会撤销电脑会话；微信手机会话不会被退出。

## 回退
关闭 DSH，将用户目录/.dsh/profiles/desktop 下安装器生成的 cordis.patch.yml.jinbao-时间戳.bak 恢复为 cordis.patch.yml，再启动 DSH。
