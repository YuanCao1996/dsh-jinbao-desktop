# 快速开始

1. 安装 [DSH Desktop](https://deepseek.com/harness/)，使用金宝官方服务无需 DeepSeek 账号或 Key。
2. 下载 [Windows ZIP](https://api.jinbaoai.top/downloads/dsh/v0.1.9/jinbao-desktop-windows.zip)，右键“解压全部”，双击 `开始使用.cmd`。[GitHub Release](https://github.com/YuanCao1996/dsh-jinbao-desktop/releases/tag/v0.1.9) 提供相同版本。不要在压缩预览窗口里运行单个文件。
3. 悬浮窗立即显示启动进度。首次安装或升级如提示关闭宿主，请保存 DSH 中的工作、关闭宿主，再启动金宝。配置完成后自动启动 DSH，并创建桌面和开始菜单的“金宝”快捷方式。
4. 新用户默认使用金宝官方服务。微信网站扫码尚未开通，当前通过设置页的 IP 试用或 App 配对登录；首批十个公网 IP 每个名额累计 1 亿模型 token，同一出口共用名额。也可在设置中配置自己的模型 API Key，已有 BYOK 配置会保留。
5. 悬浮窗显示“等待进入游戏”，自动启动支持的采集。LoL 在本机运行；王者需要一台已授权 USB 调试的 Android 手机及金宝 App 的游戏采集功能。无需选择游戏模式。多台手机连接时，请保留需要采集的一台。

手机 App 从[金宝官网](https://www.jinbaoai.top/#download)下载统一 APK，无需配对专用版本。ADB 已包含在 ZIP 中。

之后双击桌面“金宝”即可。请保留解压目录。升级时保存工作、关闭 DSH 和旧版金宝，再从新目录启动；快捷方式会更新到新目录。

## 悬浮窗

战况、装备、海克斯、对手、胜率、团战、事件和聊天共八页。时间为对局已进行时长。标题栏可拖动，设置、收起、关闭与页签可直接点击；`Ctrl+Alt+J` 切换交互与穿透，聊天会进入交互模式。收起后点击“金宝”图标展开，按住图标可拖动。游戏遮住窗口时切换无边框或窗口模式。

点击 × 或托盘菜单退出会停止本次一键启动管理器及其采集进程，宿主仍可继续使用。也可双击 `stop-overlay.cmd`。手动维护入口为 `高级维护.cmd`。

不同游戏和对局的 Agent 上下文独立，通过 DSH 原生会话持久化恢复；等待时不主动调用模型。统计数据需要攻略检索权限，未开通时可向模型咨询建议，未知战绩与胜率不会编造。海克斯选择画面 OCR 不包含在包内，可在聊天中输入选项。

## 排障

- 本机已有开发版 LoL 悬浮窗：下载版启动前识别同一 Windows 会话中的旧窗口，保留现有窗口和 DSH 配置，不再另起窗口或抢占快捷键。若 DSH 在启动后才拉起旧窗口，下载版会退出自己的窗口及采集器。此兼容行为不会把旧版自动升级为官方云端配置。
- 缺少宿主：先安装 DSH Desktop，再启动金宝。已验证 Desktop 0.2.0-rc.2；SDK 依赖 0.1.5-rc.2。
- 插件共享依赖版本不一致：不要强行覆盖；按安装器错误信息处理，维护菜单提供单独安装入口。
- 教练未启动：检查启动进度和设置诊断，确认 3081/3084 端口未被其他程序占用。
- 王者无日志：确认手机授权 USB 调试、只连接一台目标手机、金宝 App 已开启游戏采集。手机重新连接后启动器会重新检测。
- LoL 无日志：先运行客户端并进入游戏，采集器读取本机 LCU/Live API。
- 模型认证失败：核对厂商 API 前缀、模型 ID 和 Key。
- 云端额度或检索权限不足：登录身份与商业权益分别检查；BYOK 模型调用无需微信登录，检索仍需权限。
- 微信网站扫码入口未出现：网站应用审核及服务器配置尚未完成，暂用现有试用、App 配对或 BYOK。
- 退出电脑登录会撤销对应电脑会话，不会退出手机微信会话。支持续期的新电脑会话在有效期内自动轮换，但仍受原始登录的最长有效期约束。

## 回退

关闭 DSH，把用户状态目录 `profiles/desktop` 下安装器生成的 `cordis.patch.yml.jinbao-时间戳.bak` 恢复为 `cordis.patch.yml`，再启动 DSH。默认状态目录为用户目录下的 `.dsh`；设置了 `DSH_HOME` 时使用该目录。
