# 金宝独立桌面版 v0.2.4-standalone-preview.1

这是 Windows 独立桌面版预发布包，使用独立更新通道，不会改动或覆盖 DSH Desktop。

## 下载和启动

下载 `jinbao-desktop-windows.zip`，完整解压后双击 `开始使用.cmd`。默认使用金宝官方云端服务，不需要安装或登录 DSH Desktop；设置中也可以切换为自有 API Key 模式。自有 Key 模式需要本机 DSH Desktop 的运行模块，但无需同时打开 DSH 窗口。

## 本次内容

- 将独立桌面版更新到 0.2.4 预览候选，包含通用游戏身份识别、按需看图/检索、语音角色和低频播报、游戏阶段建议、截图避让与诊断等当前候选实现。
- 保留游戏悬浮窗的大框、窄条、滚动和字幕显示模式。
- 登录、设置和本机运行状态由独立桌面端提供；不要求 DSH Desktop 账号或 DSH Desktop 主窗口。
- 安装包内包含经过验证的 Node 24.22.1 Windows 运行时；不包含 ADB。

## 预览边界

- 通用游戏能力仍需按不同游戏、日志结构和画面进行实测，不保证未知游戏自动识别或策略建议准确。
- 群聊 UI 和客户端模块仍属本地预览；群聊服务端没有部署，本版本不开放群聊功能。
- 本预发布不启用付费群聊、主机托管或新的服务端计量逻辑。
- 更新安装仍要求正常退出金宝；请勿在游戏进行中安装。

## 验证

- 桌面主套件及通用游戏测试通过。
- 群聊客户端单测：82 项通过、10 项因需要已安装 DSH Windows 环境而跳过。
- 服务端本地 Redis 回归：259 项通过、1 项跳过；这些测试不代表服务端已部署或实战策略质量已验收。
- 清单文件逐项 SHA-256 校验通过；未进行真实对局、真实模型或多机实战验收。
