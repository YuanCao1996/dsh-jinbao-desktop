# 金宝独立桌面版 v0.2.6 预览版

选人时能看拍档，击杀时会夸，导师语气全线统一，海克斯"本局已选"不再认错。

本版本为**独立预览版**：需手动下载 ZIP、完整解压后双击"开始使用.cmd"，尚未加入正式自动更新通道。群聊服务端仍未部署，群聊入口保持关闭。

## 新增功能

### 1. 选人阶段显示最佳拍档

战况页在英雄选择阶段列出**已选英雄的最佳拍档**，已在本队的拍档标 `✓`，用来决定下一个选谁。

```
最佳拍档 · 选人（✓ 已在队内）
疾风剑豪：卡牌大师 66.5%✓ · 迅捷斥候 64.4% · 无双剑姬 63.6%
卡牌大师：疾风剑豪 66.5%✓ · 无双剑姬 66.2% · 无极剑圣 64.3%
```

- 数据来源：101.qq.com 海克斯大乱斗最佳拍档榜，统计日 **2026-10-31**，2000 组组合
- 覆盖 127 个英雄，每英雄最多 5 个拍档，展示前 3；登场率低于 0.3% 的组合视为小样本不采用
- 数据已内置在客户端，**选人时本地即时显示，不依赖网络或模型**
- 仅海克斯大乱斗有该数据；经典/排位不会显示这一块

### 2. 多杀即时夸奖

本人**双杀 / 三杀 / 四杀 / 五杀**会在连锁结束后约 2 秒给一句夸奖，四档程度递进；**队友四杀、五杀也会夸**（双杀三杀不夸，避免噪音）。

- 只夸**最高档**：2→3→4→5 的连锁不会连喷四条
- 外界是本人还是队友按 `KillerName` 判定，去 `#tag` 归一化后比对，同名前缀的队友不会被误认
- 语气跟随设置页所选导师（金宝 / 柳如风 / 王霸天 / 铁汁），例如五杀——
  - 金宝：五杀！这波太漂亮了！
  - 柳如风：五杀。这一波可以回放了。
  - 王霸天：五杀！全场都是你的！
  - 铁汁：五杀！这波我得给你鼓掌。
- 夸奖语音可越过 45 秒静默窗，保证及时；但夸完只安静 **15 秒**，不占满整个静默间隔，战术建议不会被拖慢
- 两条夸奖间隔不小于 8 秒，不会边说边叠

### 3. 四位导师语气统一

此前只有官方服务路径会应用导师语气，**本机自有 Key（BYOK）路径写死了"金宝"**。现在两条路径使用同一角色指令，自动播报与手动提问一致。

## 修复

### 4. 海克斯"本局已选"误判

两个症状一起修：

- **确认弹窗列出了刷新掉的候选**：弹窗此前会把"本轮历史见过的所有候选"都列出来，刷新掉的卡片仍可点选，一点就会把玩家从未拥有过的强化记进"本局已选"。现在**只列出当前面板上的候选**，并明确提示"还有 N 个卡位未识别"，不再用旧名字补齐。
- **聊天记录归属失效**：游戏内格式是 `玩家名（英雄）已质变了…`，代码先剥掉括号内容再找英雄名，导致自己获得的海克斯永远判不成"自己"；同时整句被剥空后置信度恒为最低，整条被丢弃。现在归属取"动词之前"的最后一个英雄名，置信度直接判原始文本，并打上 `log-confirmed` 来源标记。

另外移除了一个会绕过归属判定的 `scoreboard-icon` 旁路（已确认全仓库无产出方，属死代码）。

### 5. 聊天文字识别改进

聊天文字此前是在**整屏**上做 Windows OCR，中文被认坏（`已终结了` → `已 终 了`、`无人能挡` → `无人能了`），海克斯名一旦错字就整条丢弃。

- 改为**裁出聊天区、放大 3 倍**（高质量双三次）后再识别，实测同一张图：`已经无人能挡了`、`已经主宰比赛了`、`残月之肃`、`已终结了` 全部恢复正确
- 画面无变化时**复用上次识别结果**，不重复识别
- 裁剪识别失败时**回退到整屏行**，不会把聊天区整个丢掉
- 动词正则容忍 OCR 常多插的"经"（`已经质变了` / `已经选择了`），不再整条漏掉

## 升级与回滚

- 换包保留配置：预览状态在 `%USERPROFILE%\.jinbao-cloud-preview`，第一次使用可能需要重新邮箱登录

- 回滚：重新解压上一个 0.2.5 预览包即可，配置目录保留
