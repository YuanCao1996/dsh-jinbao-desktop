# 0.1.10

- 自动更新：启动及每六小时检查，后台下载并验证 Ed25519 签名、SHA-256 和完整文件清单；下次启动切换，新入口启动失败回退。用户配置、凭据和对局保留，插件变更仍使用原有 DSH 重载流程。
- 悬浮窗：背景不透明度保存，滚轮直接操作，刷新保留阅读位置；对手页匿名、固定列对齐并按近期胜率排序。
- 简化：只保留开始使用和高级维护两个操作入口，统一使用说明；官网统一手机与电脑下载，设置页折叠备用登录及诊断。
- Agent：使用 DSH 原生游戏预设与上下文压缩；收窄工具范围，放宽有界模型请求大小至 512 KiB，解决正常 Agent 请求触发 413 的问题。

验证包括客户端自动测试、原生 WPF 交互、中文与空格路径下的更新切换/失败回退、ZIP 路径检查、真实 DSH 的双游戏日志与会话恢复，以及模拟模型的多轮原生压缩。微信网站扫码和手机完整对局仍需对应实机验收。

0.1.9 及更早版本需要先手动下载一次 0.1.10 才能获得更新器。自动更新仅覆盖金宝，DSH Desktop 和手机 App 不由本更新器管理。
