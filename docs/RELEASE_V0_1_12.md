# 0.1.12

海克斯按当前英雄的适配名次排序，移除效果详情。识别当前三选一面板，三个位置分别重掷后更新当前推荐，旧选项不再参与排序；每轮最多记录六个已见选项。仅采集前台游戏窗口，使用 Windows 内置中文文字识别；不会保存或上传截图。识别失败时保留未知状态，不编造候选。

胜率合并进原对手页，页签统一为“胜率”，展示英雄样本胜率及双方近期战绩。隐藏玩家名，战绩按胜率降序排列。

聊天页进入时激活窗口并聚焦输入框；请求失败恢复未发送成功的问题，并区分登录、权限、额度和网络错误。

验证：原生 WPF 交互自检、聊天官方服务连通测试、海克斯三位置重掷和过期请求回归测试通过。真实游戏内 OCR 识别率仍需根据实际面板验证。

0.1.10 及以上版本支持后台下载，下次启动应用。若提示 DSH 插件需要更新，请先保存会话并正常退出 DSH，再重新启动金宝。
