# 0.1.15

大乱斗选英雄阶段自动打开胜率页，展示当前己方、可见对手及备选席英雄的样本胜率和强度（T0、T1 等），按英雄胜率降序排列。换英雄、重掷和备选席变化后自动更新，不需要等到游戏开始。未公开英雄不会推测，缺失数据明确显示暂无。

通过本机客户端只读接口读取英雄列表和选人会话，不读取玩家战绩或发布玩家标识。同一选人会话缓存已查询英雄，换人时仅检索新增英雄。取消选人会清空候选，进入游戏后切换到局内状态。

验证：46 项回归测试及原生 WPF 检查通过，覆盖选人投影、备选变化、查询缓存、无个人选定英雄时仍可查询、取消与进游戏切换，以及自动打开胜率页。真实选人界面的联调仍待游戏客户端进入对应阶段验证。

支持签名自动更新；本次包含 DSH 扩展更新，若宿主仍运行旧扩展，需要保存会话并正常退出 DSH 后完成安装。
