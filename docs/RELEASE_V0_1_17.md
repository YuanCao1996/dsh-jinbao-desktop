# 0.1.17

补回事件页中的装备购买和海克斯选择。历史记录的 chat_events.purchase、augment_picked 和 augment_mutate 均参与事件展示，显示对局时间、装备/强化名及可确认的英雄，不展示玩家名或效果详情。海克斯候选、刷新及面板关闭也保留。

当前采集器复用现有游戏聊天解析器，用 Windows 原生 OCR 读取前台游戏内的购买和强化播报。英雄与物品名称使用本机客户端只读接口校验；不新增云端识别、不保存或上传截图，不记录原始聊天文本。此路径仍受聊天栏可见性和 OCR 识别率影响，没有播报就不能据此保证确认选择。

库存变化另记为“装备更新”，不把合成、赠送、出售或撤销误称为购买；首次读取只建立快照，不补造历史。低置信度海克斯显示“疑似”，归属未知不当作自己，队友强化不会进入本人已选列表；面板消失也不会自动猜选中了哪张。

验证：52 项回归测试通过。回放本机旧版 45 份历史日志，76 条购买播报、195 条海克斯记录均能进入事件展示，低置信度推断进入本人已选的数量为 0。原生 OCR 离线识别及坐标输出通过；新增聊天采集仍需实际游戏联调。

支持签名自动更新。本次包含扩展与采集器更新，运行旧扩展时需保存会话并正常退出 DSH 后完成安装。
