# 0.1.18

新增同一微信账号的电脑到手机页面同步。手机使用官网统一 App 1.0.1-beta.22，从“我 → 助手设置 → 电脑对局”查看战况、装备、海克斯、英雄胜率、关键事件和电脑聊天记录。已绑定账号自动发现电脑，多台电脑可切换；本期为只读展示。

账号关联使用服务器既有的统一用户身份，不按 IP 或昵称关联。免登录试用电脑首次需在设置中生成配对码，由登录微信的手机确认；同步凭据与模型计费凭据分开，保留原有 IP 试用额度、激活权益及自有模型配置。

设置中显示同步状态，可关闭或重新开启同步。仅上传最新视图，不上传模型密钥、身份凭据和完整数据库。服务端按账号隔离，最多保留 10 台电脑，一天过期。手机切换账号清除旧内容，离开页面停止轮询。

验证：桌面 54 项测试、私有后端测试、真实 Redis 账号隔离和设备数量测试，以及 Android 原生页面和格式测试通过。统一 APK 与原官网包签名一致。当前无连接手机，实机微信绑定及显示仍待用户验证。

支持签名自动更新。本次包含 DSH 扩展更新，需保存会话并正常退出旧 DSH 后安装。
