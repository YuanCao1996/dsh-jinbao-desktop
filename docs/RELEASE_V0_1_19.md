聊天接入自动教练使用的 DSH 原生 Agent：同一游戏、同一对局共用持久会话、工具调用与上下文压缩。主动提问优先于排队的自动观察，允许展开回答；自动播报仍保持短句。

关键事件、装备变化、海克斯候选与选择、播报、聊天记录纳入共享上下文。本机保存跨局摘要和用户明确要求记住的偏好。完整已采集日志通过分页工具按需读取，升级前的原始日志也可查询。历史事实标明所属对局，不推定为本局状态；未采集到的事实仍显示未知。

补挂 DSH 原生 web_search / web_fetch，搜索复用现有服务配置，无需另填 DeepSeek 搜索密钥。攻略检索权限与模型权限继续独立。取消聊天直接调用模型的旁路。

验证：61 项客户端自动测试通过。独立真实 DSH Desktop 实例验证自动播报与聊天共用会话、日志/跨局记忆/攻略/偏好工具调用及重启恢复；实际联网搜索返回结果，英雄官网读取 HTTP 200。模型回复使用测试模型，未将模拟回答视为游戏策略质量验证。
