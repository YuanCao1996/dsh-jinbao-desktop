# 0.1.21

接入手机主动聊天。官网统一 App 1.0.1-beta.23 的“电脑对局 → 聊天”新增输入框与发送按钮，问题交给电脑上的同一 DSH Agent，复用对局上下文、历史记忆和检索工具。电脑与手机共同显示问题和回答，并区分提问来源。

消息由服务器按微信账号与电脑隔离传递，绑定发出时的对局。电脑离线或版本过旧时禁用手机发送。请求 ID 去重、回执持久化与有界队列避免网络重试重复调用模型；执行中重启提示失败，切局后不把旧问题应用到新对局。

验证：65 项客户端测试通过；后端账号隔离、旧对局拦截、请求去重及真实 Redis 原子领取测试通过。统一 App 原生界面测试与签名构建通过。完整真实手机和真实对局仍需实机验收。

更新电脑版后保存工作，正常退出 DSH，再打开金宝。手机通过官网更新统一 App，无需更换包名或另装分支版本。
