# 0.1.22

修正 LoL 海克斯大乱斗的模式提示词。此前自动播报虽有人设说明，聊天缺少相同约束，采集模式也未进入共享上下文，可能产生经典模式建议。

现在自动播报、电脑聊天和手机聊天统一使用实际模式。KIWI 按海克斯大乱斗处理，ARAM 按普通大乱斗处理，CLASSIC 不误认成海克斯；模式随对局状态和历史记忆保留。建议围绕单线、阵容、装备与当前强化，避免经典模式的分带、打野控龙、回城购买和符文页套路。强化单槽刷新后只比较当前三个候选，已见记录不等于已选。

检索要求匹配英雄、模式与当前版本，不把通用排名或其他模式统计当成本模式结论；移除过时的强化稀有度固定描述。玩法规则优先于历史建议，发现旧建议套用经典模式时应纠正。

验证：69 项客户端测试通过；打包后的真实 DSH 宿主验证模式规则进入自动播报、电脑聊天和手机聊天请求，并检查会话恢复、工具链与账号隔离。模型使用受控测试响应，真实对局的建议质量仍需实战验收。

正常退出 DSH 后再打开金宝即可应用自动更新。统一手机 App 1.0.1-beta.23 无需重新安装。
