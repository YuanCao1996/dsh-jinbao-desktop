# 0.1.23

修复海克斯页误报中文文字识别不可用。截图脚本的整数写法不兼容系统自带 Windows PowerShell 5.1，导致前台采集路径在检查识别引擎前失败。现在使用兼容写法，并区分中文语言包缺失、识别组件不可用和临时截图失败；错误恢复后自动清除提示。

装备购买与装备栏变化同步到装备页的“装备动态”；当前装备仍以实际装备栏为准，购买记录不冒充仍然持有。日志中的强化选择同步到海克斯页，并保留归属与置信度。支持直接事件和聊天事件流中的结构化购买、强化选择消息，队友或归属不明的强化不会记为自己已选。

海克斯页当前三个候选按英雄适配排序后同步显示到战况页；单槽刷新会移除旧选项，面板关闭后清除候选，已确认选择显示为本局已选。相同内容沿现有同步链路传给统一手机 App。

事件按到达顺序追加，最新消息始终在最下方；打开事件页或收到新事件时自动滚到底部。其他页面与聊天的阅读位置规则保留。

验证：72 项客户端测试通过；本机 Windows PowerShell 5.1 与真实中文 OCR 引擎成功识别合成测试图中的三个海克斯和购买消息；原生 WPF 悬浮窗事件滚动、透明度、缩放、拖动、关闭及聊天滚动测试通过。真实游戏画面识别效果仍需对局验收。

正常退出 DSH，再打开金宝即可应用更新。统一手机 App 1.0.1-beta.23 无需重新安装。
