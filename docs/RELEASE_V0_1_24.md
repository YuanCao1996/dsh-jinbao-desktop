# 0.1.24

对局时间、英雄、等级、KDA 与金币移到战况正文，其他页不再占用一行公共摘要。窗口最小高度从380降为220像素，并保留尺寸恢复与缩放。

装备页隐藏敌方装备明细，但模型仍使用敌方各英雄装备。当前装备、敌方装备或海克斯变化后，通过同一 DSH Agent 自动生成下一件优先装备、后续顺序及理由。更新采用2秒稳定等待和30秒调用间隔，避免状态轮询重复调用。所有已确认海克斯参与决策；尚未确认的选择，逐轮按有可信英雄适配排名的当前候选最高项推测，明确标注待确认，不写入已拥有。单槽刷新会替换旧推测，确认选择后用实际结果替代。装备变化期间旧建议失效，跨局或已过时的异步结果不会写回。

胜率页增加我方与敌方五名英雄样本胜率的算术平均。每侧五名英雄均有数据才计算，缺失时标明已获取数量；备选不参与，不把均值称为本局预测概率。

自动播报与聊天明确要求结合事件页关键时间线；上下文过大时仍保留最近关键事件，完整历史继续通过日志工具查询。移除残留的刷新推荐按钮提示。

验证：77项客户端测试通过，覆盖强化推测替换、全部已拥有强化、敌方装备输入、自动出装调用、限流与跨局隔离、双方均值以及超长上下文的事件保留。原生悬浮窗及隔离的真实DSH链路验证通过；模型使用受控测试响应，实战策略质量仍需对局验收。
