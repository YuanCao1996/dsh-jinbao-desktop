# 0.1.25

新增海克斯交互确认：三选一面板关闭后先留3秒等待日志确认，仍未确认才显示按当前英雄适配排序的候选按钮，点击实际选择即可。大框显示确认区，窄条弹出小型确认卡，静默模式只显示提示。保留“都不是/暂不确认”；确认绑定游戏、对局、轮次及当前候选，拒绝过期或刷新后的旧按钮。确认写回日志、已拥有强化及共享记忆，立即触发出装更新；排名推测不再冒充已选。

设置增加大框、窄条、静默小球切换。窄条支持横向滚动与淡入淡出字幕，按实际文字宽度分行。播报使用有界队列、事件去重和过期淘汰，模式切换不重放大框已呈现消息；保留六页、缩放与透明度。

新增 DSH 原生工具 inspect_latest_screen，按需采集当前游戏窗口或强化区域，通过现有官方/BYOK模型路由提交有界内嵌图片。校验当前游戏、对局与截图时间，不开放模型指定任意本地文件路径；截图或模型失败明确返回不可用，继续依据日志，不编造画面。观察结果与已确认事实分开。

官方代理补齐有界JPEG/PNG图片支持，仍复用原OpenCode Go模型与计量。真实官方模型已读出仅存在于测试图片中的随机数字。BYOK模型不支持图片时会明确降级，不能宣称已看过截图。

搜索增加海克斯模式约束、缓存与并发去重；中文正文在原生HTTP安全传输上补充meta字符集识别和乱码拒绝。关键英雄、装备、强化着色；显示真实工具执行状态，不展示模型思维链。语音输入支持点击录音、识别后编辑再发送；可选本机中文语音播报，默认关闭，不持续收音，依赖系统已安装语音组件。

验证：83项客户端测试通过；图片鉴权/计量与JPEG验证测试通过；原生窗口模式、字幕、确认、高亮及旧交互验证通过。隔离DSH宿主验证原生工具与图像传输、确认回写及共享会话。真实游戏画面、麦克风输入与语音播报仍需实机验收。

正常退出DSH，再打开金宝应用自动更新。统一手机App不需重装；此次新增确认按钮与显示模式位于电脑端。
