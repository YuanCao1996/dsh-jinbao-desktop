# 0.1.29

电脑游戏默认不启动或轮询 ADB。USB 手机采集改为设置页显式开启，和手机查看电脑对局的云端同步开关分开。开启后使用随机独立端口、前台运行的专用 ADB，关闭采集或退出金宝时只清理自有进程，避免留下共享后台服务。

已有可用金宝扩展的 DSH 正在运行时，延后安装扩展更新，继续使用现有服务，不再要求立即关闭 DSH。检测到用户正常退出 DSH 后再安装。首次安装且 DSH 已运行时仍需要退出一次才能加载新扩展，不自动强退 DSH。

验证：93 项测试通过，覆盖默认不查询 ADB、显式开启/关闭、鉴权与持久化、热插拔、自有采集器退出、运行中延后升级。真实 Windows ADB 独立端口启动与退出关闭测试通过，未触碰共享5037端口。已核实并清理本机无外部客户端的旧金宝ADB孤立进程。
