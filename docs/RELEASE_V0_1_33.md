# v0.1.33

启动金宝后自动打开设置网页。邮箱验证码登录后显示绿色账号卡片、保存状态并收起登录表单；已有体验账号可绑定邮箱，保留原额度和自有模型配置。

- 网页移除“一键开通”和 USB 手机采集区，减少首次使用的操作和干扰。
- 维护操作整合到网页“维护与诊断”：检查状态、安排扩展修复和退出金宝。修复等待正常退出 DSH，不强制结束宿主。新版安装包根目录不再附带“高级维护.cmd”；内部维护菜单仍可用于无法打开网页时排障。
- 手机浏览器打开 https://api.jinbaoai.top/desktop/mobile，使用电脑已绑定的同一邮箱，查看六页对局信息并向电脑 Agent 提问，无需微信。手机会话不能上传电脑状态或执行回答。
- 原 App 微信配对保持兼容；本次新增手机网页入口，不另发手机 App 分支。随机配对码不是本版新增入口。

验证：桌面自动测试 104 项通过；邮箱/同步专项 4 项通过，其中验证码使用隔离真实 Redis。公网手机页面和登录边界已验证；实际手机邮箱登录与聊天还需用户端验收。邮件发送、收信和电脑邮箱绑定已实测。

0.1.32 为内部邮箱预览包，正式版本直接升级为 0.1.33。
