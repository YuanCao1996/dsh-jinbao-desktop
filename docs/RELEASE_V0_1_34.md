# v0.1.34

更新过程现在显示检查、下载、验证、准备文件和安装状态。设置网页展示下载百分比、大小、速度及本次更新内容。

- 更新成功在网页顶部保留通知，点击“知道了”后收起；后续检查不会覆盖结果。启动失败回退时显示独立结果提示，原有设置保留。
- 新增“准备安装更新”：确认后退出金宝，等待用户保存工作并正常关闭 DSH，再自动安装、启动和打开网页。不会强制结束 DSH。选英雄或对局中禁止开始安装，启动器执行前会再检查一次。
- 等待 DSH 关闭期间可取消；等待超过 30 分钟自动取消，原启动入口继续可用。执行前再次验证签名和安装包文件。
- 网络失败支持重试，已验证的待安装包不会因检查失败而丢失。损坏或验证失败的下载不替换当前版本。

108 项测试通过，覆盖下载进度、成功提示持久化、结果确认、等待与取消、文件再次验证、账号和更新接口边界，以及原生 Windows 更新入口回退。本机实际 DSH 未被强制重启。

旧版首次升级到本版，仍需正常退出金宝和 DSH，再打开原启动入口一次；此后可以使用新版的自动接续安装流程。
