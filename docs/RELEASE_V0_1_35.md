# v0.1.35

修复悬浮窗字幕和滚动播放，按手机 App 的交互规则对齐。

- 字幕改为透明背景、文字阴影和两行向上推进；横向滚动停在最后一屏，保留 3 秒阅读时间再收球。
- 修复长消息 30 秒被截断、队列超过 8 条丢消息、切换显示模式清空队列的问题。普通建议排队并加速当前播放，只有紧急消息抢占。
- 空闲自动收球保留字幕或滚动模式，新建议自动展开；手动静默保持静默。菜单打开、确认选项显示和拖动窗口时暂停播放。
- 窄条支持拖动右下角调整宽度并保存；正文大小同时作用于字幕和滚动。外观设置从窄条打开时自动展开大框。

109 项自动测试通过，新增 Windows WPF 播放回归覆盖 19 项行为；原生窗口自测通过，已检查实际渲染图。尚未进行真实游戏与手机的同步实测，不能视为两端像素完全一致。

在设置网页检查更新，待新版本就绪后点击“准备安装更新”，按提示保存工作并正常关闭 DSH。新版自动接续启动，账号与窗口设置保留。
