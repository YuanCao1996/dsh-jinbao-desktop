- 聊天完整回答不再静默截断为 4,000 字符。明确要求 DSH 的回复工具提交全部回答，拒绝把主动聊天作为空字符串静音处理；自动播报的静音规则保留。

- 保留 DSH 原生会话、恢复和工具链；未引入另一套 Agent 框架。

验证覆盖原生监控队列、压缩失败后单次恢复、完整回答、空回复拒绝、重启恢复、账号隔离、累计／每日额度及故障提示。模型与 SDK 会话执行使用测试替身；尚未进行真实云端模型加游戏的端到端实测。
