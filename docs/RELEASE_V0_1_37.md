# v0.1.37

手机 App 通过短配对码连接电脑，不要求手机微信账号与电脑邮箱账号一致。

- 设置网页直接展示“连接手机 App”和“生成配对码”。配对码为 8 位纯数字，5 分钟有效；现有 App 已支持该格式，无需更换 APK。
- 在手机“我 → 连接电脑”输入配对码并确认，电脑自动保存连接并开始同步。随后在 App“电脑对局”查看战况、装备、海克斯、胜率、事件和聊天。
- 修复邮箱身份优先级覆盖 App 配对身份的问题。同步使用配对凭据，电脑模型仍使用原邮箱账号或自有 API Key，额度不转移；退出邮箱也不清除独立手机连接。
- 配对成功后重启自动恢复。换手机重新配对会清理原同步快照并立即上传新连接；可在网页暂停、恢复同步。

回归覆盖邮箱与配对凭据分离、BYOK 保留、重启恢复、退出邮箱保留配对、换绑定清理旧快照及纯数字配对码生成。服务器已验证真实返回 8 位数字，保留原 App 的确认与过期检查。
