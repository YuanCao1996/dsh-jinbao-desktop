# v0.1.40

桌面悬浮窗聊天支持用户主动添加本机图片。

- 点击“添加图片”选择 JPG、PNG 或 BMP；发送时转为受大小限制的 JPEG，图片不写入对局日志。聊天记录会标明该问题带有附图。
- 图片先经视觉模型观察，再把观察结果交给同一 DSH 对局 Agent 结合日志回答。观察不会覆盖已确认的装备、英雄或强化事实。
- 视觉模型不可用时，Agent 会收到明确的失败状态，继续依据日志回答，不声称看到了图片。
- 仍可使用“看当前画面”让 Agent 按需查看正在玩的游戏窗口。

已通过 Windows 原生悬浮窗、图片大小和格式限制、视觉失败回退，以及本地聊天到 DSH Agent 的集成测试。
