# v0.1.43

优化海克斯三选一与单卡刷新识别。

- 按左、中、右位置分别确认名称；已确认面板后，单个位置连续两次识别稳定即可更新，其他卡片漏识别不会阻塞刷新。
- 首次识别到两个不同位置时即可展示已知候选的排名，并提示剩余位置继续识别；单个悬停提示不会被误当成三选一面板。
- 每个位置保留一次刷新、每轮最多六个候选；名称歧义、重复和刷新动画不消耗识别记录。
- 查询新卡片期间保留未变化卡片的已有排名，旧卡片不会被延迟查询结果重新显示。
- 采集保持单任务运行，减少识别完成后的空等；连续五次有效空画面才判定面板关闭。

已使用历史真实三选一截图及分槽回放验证识别，并覆盖单卡漏识别、动画、切出游戏和延迟排名查询。
