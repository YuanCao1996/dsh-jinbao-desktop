# 独立桌面预览版验收记录

版本：0.2.0-standalone-preview.6；日期：2026-10-25。

## 已通过

- 桌面回归 306 项全部通过，包含 LoL 数据联动、原生 DSH Agent 工具链、会话恢复、原生压缩、手机配对聊天、签名更新和安全解压。原生工具链使用已安装 DSH 的实际组件；部分模型回答与服务通过夹具构造，不等于真实厂商模型验收。
- 安装包完整解压到中文目录后，使用包内 Node 启动；进入本机模式时能提取已安装 DSH 的模块；配置与加密密钥跨进程重启保留；正常退出。
- 官方云端的通用游戏事件、当前局日志分页查询、截图计划回执已部署到隔离桌面服务。后端分别通过 17 项 Python、55 项原生 Node 和 2 项手机同步定向测试。
- 默认官方模式不要求本机 DSH；本机模式复用原生 DSH。包内不附带 ADB，不需要 Android 采集进程。
- 从公开 HTTPS 更新源实际下载 0.2.0，验证签名、ZIP 摘要及每个文件，使用管理入口启动更新后的进程，取得健康回执并正常退出。此验证使用隔离状态目录，没有修改用户现有安装。

下载与独立更新源已上线，GitHub 发布为 [v0.2.0-preview.6](https://github.com/YuanCao1996/dsh-jinbao-desktop/releases/tag/v0.2.0-preview.6)。原 v0.1.49 正式更新源保留。发布验收同时发现 API 与官网域名证书于 2026-10-24 到期，已续期并配置自动续期；验证下载全过程保持 HTTPS 证书校验。
