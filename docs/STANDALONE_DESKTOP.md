# 独立桌面版：架构、使用与验收

此文对应 `0.2.2-standalone-preview.1`，独立于 v0.1.x 插件启动方式。

## 两条 Agent 路径

金宝客户端统一负责设置、凭据、采集、悬浮窗、更新和手机配对。官方服务调用隔离的服务端 DSH；自己的 API Key 调用本机 DSH 原生 Agent 模块。客户端没有另写一套会话或推理框架。

本机模式只从已安装 DSH 的应用归档中提取依赖到独立缓存，保留依赖许可证，校验路径与内容摘要。不读取原 DSH 账号、会话或用户插件，不修改原 DSH 配置，不需要另开 DSH 窗口。原生会话按游戏与对局隔离，支持恢复和压缩；当前事实与完整事件仍通过工具读取。

凭据由 Windows 当前用户 DPAPI 加密。自有模型密钥不发往金宝模型服务器；资料库查询仍按独立的服务权限授权。切换调用方式会取消旧请求，避免旧回答进入新链路；手动聊天可抢占自动建议。

## 游戏与日志

- LoL：自动检测客户端，读取本地只读 API；三选一通过中文 OCR 补充。重掷稳定确认后重排当前候选。
- 王者：原有日志适配与云端路径复用。可读取已有结构化王者日志；这不等于电脑版直接采集手机画面。默认不启动或附带 ADB。
- 通用窗口：设置中明确选择一个窗口后，才在其前台时截取窗口内容。复用原有自适应采集模块；DSH 可建议区域、分辨率及频率，本地继续执行频率预算和范围校验。LoL 等专用采集优先。
- 通用日志：设置中选择一个本机 `.log`、`.jsonl` 或 `.ndjson` 文件。支持 UTF-8 分段、游标恢复和有界追尾；每次最多处理 100 行，普通文本每行保留前 2000 字符，超长内容标记截断。路径只能由本地设置页提供，模型不能选择文件。历史查询按当前对局分页，不将全部文件塞入模型请求。

未知游戏或模式不自动套用 LoL、王者或金铲铲规则。截图观察与确定状态分开；看图不可用时继续依据日志，并说明没有获取到画面。

## 更新与手机

独立版更新使用 `/downloads/jinbao/` 通道，旧版插件包使用 `/downloads/dsh/`。签名覆盖运行类型、版本、下载地址、文件摘要及说明；签名或文件检查失败时不执行。安装时保持用户状态目录，游戏中不安装；新版启动失败可回退。预览包未替换 v0.1.x 正式更新源。

手机使用既有 8 位配对码，配对身份独立于电脑模型账号。同步和主动提问沿用同一客户端 Agent，防止重复推理和跨对局回复。手机胜率表已补团队局势文字，修复位于统一 APP 源码。

从 0.2.1 预览版起，同一设备只需首次配对。电脑自动将现有有效配对升级为独立的设备凭据，按当前 Windows 用户加密保存；重启、更新、退出模型账号和暂停同步都保留配对。设备凭据只能同步这一台电脑，不授予模型账号或其他电脑的权限。设置中“暂停同步”保留连接，“解除配对”会撤销服务端凭据并清除本机连接。清除本机数据、重装系统或旧配对已在升级前过期时，需要重新配对一次。手机自身的微信登录失效时可能需要重新登录，设备无需因此重新输配对码。

## 验收边界

0.2.4 修复候选包使用原生 `jinbao.exe`，`开始使用.cmd` 只启动该文件，不执行 VBS。为兼容旧版签名更新检查，包中暂留只有一行注释的 `start-preview.vbs`；它没有可执行语句。原生入口尚未作代码签名，也尚未通过用户所用杀毒软件复测，不能承诺没有告警。

基础英雄胜率、Top10 海克斯和出装资料查询与 Agent 自主检索额度分开，仍要求有效服务权限。空结果可重试，不把缺失数据填成虚构胜率。敌方成装变化写入事件与决策上下文，散件保留在底层事实中，界面动态只展示成装。

实验性队友大招提醒读取屏幕上可见的我方头像与就绪圆点，复用现有 OCR 截图，不读取进程内存。须确认我方阵营、至少三张同组头像并连续识别两次；死亡队友、敌人、自身、隐藏 HUD、低置信度和过期图片不触发。就绪提醒四秒失效，状态变化立即撤回，不猜冷却秒数。已验证历史样本的 1080p、810p、720p 缩放，其他 HUD 布局仍待实际对局验收。

自动化测试涵盖原生窗口、候选重掷、数据页联动、原生 DSH 工具调用、会话恢复与长会话压缩、手机请求、签名更新及独立打包。模型夹具测试证明原生工具链和协议行为，不代表所有模型厂商或实际游戏场景均已通过。

发布前仍需真实 LoL 对局、实际手机与自有模型密钥的人工验收。团队百分比是未经结果校准的“局势估计”，尚未计入完整经济、建筑和复活信息，不能当作统计胜率或胜负保证。
