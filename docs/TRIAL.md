# 申请电脑试用

[打开公开试用申请页](https://api.jinbaoai.top/desktop/trial)

1. 填写显示昵称、联系邮箱或微信号、体验用途，提交申请。
2. 保存页面生成的私密领取凭证，等待人工审核。换浏览器时可粘贴凭证查询；请勿转发。
3. 管理员核对并审核通过后，在同一页面点击「查询审核结果」，领取自己的单次激活码。
4. 使用 v0.1.1 或更新扩展，在 DSH 设置页粘贴激活码，点击「激活并登录」，选择并保存「金宝云端模型」。

不需要安装金宝 App。每个账号独立计量：7 天，每日检索 100 次、云端模型 100000 tokens。额度按 UTC 自然日计算，权益从审核通过时开始。激活码须在审核通过后 24 小时内兑换，会话最长 7 天且不超过权益到期时间。

这是人工审核申请入口，不会自动开通；联系方式由管理员私下核对，尚未提供邮箱自动验证或通知。每个联系方式 7 天内限申请一次。丢失领取凭证、申请过期或退出后需联系管理员处理。

领取凭证和激活码属于个人凭据，不写入 GitHub、分享链接或公开评论。审核时间以管理员处理为准。
